# Этап 2.3 (PARALLEL, после 1.1) — внятная трансляция конфликта версий (409)

## Проблема
409 доходит до агента дословным текстом Трекера: «Задача: не удалось сохранить изменения,
попробуйте ещё раз». Агент понимает это буквально и повторяет запрос с той же `version` —
конфликт воспроизводится бесконечно. Специальной обработки 409 в инфраструктуре нет
(`CONFLICT = 409` в `types.ts` объявлен и нигде не используется, кроме ветки `unique`
в create-issue).

## Решение
На границе HTTP-слоя дополнять ошибку 409 действенной подсказкой: это конфликт версий,
нужно перечитать сущность, взять актуальную `version` и повторить; слепой ретрай не
поможет. Исходное сообщение API сохраняется (не подменяется).

## Кейсы и границы
- 409 при обновлении задачи с устаревшей `version` → подсказка добавлена
- 409 в ветке `unique` create-issue → поведение НЕ меняется (там 409 штатный и уже обработан)
- прочие статусы → текст не меняется
