# Инвентарь annotations — перенесён

Пакет 1.3 перенёс этот инвентарь в постоянное место:

**[packages/framework/dev-client/docs/tools-annotations-inventory.md](../../packages/framework/dev-client/docs/tools-annotations-inventory.md)**

Причина: правила проекта требуют удалить папку плана после финальной валидации всего плана, а
верификационный артефакт, на который опирается защита записи `mcp-dev`
(`packages/framework/dev-client/src/write-policy/`), не должен умирать вместе с планом.

Итоговый файл содержит: три канала получения данных и их слепые пятна (статический парс,
реальный `tools/list`, сверка по коду), полную таблицу 153 инструментов, результат семантической
сверки всех `readOnlyHint: true` инструментов по коду и статус единственного известного
расхождения (`yandex-wiki / download_attachment` — устранено в коде до начала пакета 1.3, коммит
`6a19b7ad`).
