# Пакет 2.1 — Скрипты и документация `yandex-tracker` (parallel)

**Зависит от:** 1.2
**Параллелен:** остальным пакетам 2.x
**Модель исполнителя:** младшая.

## Набор файлов

- `packages/servers/yandex-tracker/package.json` — **только секция `scripts`** (devDependency уже добавлена пакетом 1.2, `package-lock.json` не трогаем)
- `packages/servers/yandex-tracker/CLAUDE.md`
- `packages/servers/yandex-tracker/dev-calls.example.jsonl`

Файлы других серверов, framework-пакетов и корня — **не трогаем**.

## Что делаем

1. Добавить скрипты `tools:list`, `tools:call`, `tools:batch` с `--server-name fractalizer_mcp_yandex_tracker` и `--package-dir .`.
   **Имя `mcp:list` не занимать** — оно уже означает «список MCP-клиентов и их статус».
2. Положить пример батча на 2–3 read-вызова (инструменты с префиксом `fr_yandex_tracker_`).
3. Добавить в `CLAUDE.md` сервера короткий раздел: как прогнать затронутые кейсы после доработки, что запись закрыта флагом, что вызовы идут в боевой сервис.

## Definition of Done

1. `npm run tools:list` печатает список инструментов (ожидаемо 92) с классами read/write/local-side-effect.
2. `npm run tools:batch -- dev-calls.example.jsonl` проходит и печатает JSONL результатов.
3. Если сервер не подключён у исполнителя — DoD 1 и 2 считаются выполненными при получении **внятного** отказа `notConnected` (а не `unparsable` и не падения), и это отмечается в отчёте пакета.
4. `npm run validate:docs` проходит — лимит размера `CLAUDE.md` не превышен.
5. `npm run validate:quiet` в пакете проходит.
6. `package-lock.json` в диффе пакета отсутствует.

## Факт исполнения (пакет 2.1, зафиксировано оркестратором)

Пакет **сделан**, DoD 1–6 закрыты, дифф ограничен тремя файлами набора. Реальный прогон против
живого трекера: `tools:list` — 92 инструмента (39 read / 52 write / 1 local-side-effect),
`tools:batch` по примеру — 3 вызова, 0 провалов, exit 0. `CLAUDE.md` 569/600 строк.

Решение, общее для 2.1–2.3: скрипт `tools:list` включает `--json` — вывод предназначен агенту, а
не человеку, и должен быть машинно разбираем без дополнительного флага. Человекочитаемая форма
доступна прямым вызовом `mcp-dev list` без `--json`.
