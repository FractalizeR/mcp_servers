# Пакет 2.2 — Скрипты и документация `yandex-wiki` (parallel)

**Зависит от:** 1.2
**Параллелен:** остальным пакетам 2.x
**Модель исполнителя:** младшая.

## Набор файлов

- `packages/servers/yandex-wiki/package.json` — **только секция `scripts`** (devDependency уже добавлена пакетом 1.2, `package-lock.json` не трогаем)
- `packages/servers/yandex-wiki/CLAUDE.md`
- `packages/servers/yandex-wiki/dev-calls.example.jsonl`

Файлы других серверов, framework-пакетов и корня — **не трогаем**.

## Что делаем

1. Добавить скрипты `tools:list`, `tools:call`, `tools:batch` с `--server-name fractalizer_mcp_yandex_wiki` и `--package-dir .`.
   **Имя `mcp:list` не занимать** — оно уже означает «список MCP-клиентов и их статус».
2. Положить пример батча на 2–3 read-вызова (инструменты с префиксом `yw_`).
3. Добавить в `CLAUDE.md` сервера короткий раздел: как прогнать затронутые кейсы после доработки, что запись закрыта флагом, что вызовы идут в боевой сервис.

## Definition of Done

1. `npm run tools:list` печатает список инструментов (ожидаемо 36) с классами read/write/local-side-effect.
2. `npm run tools:batch -- dev-calls.example.jsonl` проходит и печатает JSONL результатов.
3. Если сервер не подключён у исполнителя — DoD 1 и 2 считаются выполненными при получении **внятного** отказа `notConnected` (а не `unparsable` и не падения), и это отмечается в отчёте пакета.
4. `npm run validate:docs` проходит — лимит размера `CLAUDE.md` не превышен.
5. `npm run validate:quiet` в пакете проходит.
6. `package-lock.json` в диффе пакета отсутствует.

## Факт исполнения (пакет 2.2, зафиксировано оркестратором)

Пакет **сделан** в части своего набора файлов: три скрипта `tools:*` в `package.json` (форма та же,
что у 2.1 и 2.3), раздел в `CLAUDE.md` (139/600 строк), `dev-calls.example.jsonl` из трёх read-вызовов
(`yw_ping`, `yw_get_page`, `yw_search`). Дифф ограничен набором, `package-lock.json` не тронут,
`manifest.json` откачен.

Решение исполнителя, уточняющее план: в примере батча `fields` передаётся строкой через запятую
(`"fields": "title,description"`), а не массивом — этого требует `WikiFieldsSchema` wiki, в отличие
от tracker и ticktick, где `fields` — массив. Форма JSONL от сервера к серверу не универсальна.

## DoD 2 не закрыт по внешней причине — Yandex Wiki API отдаёт 503

Отчёт исполнителя объявил DoD 2 пройденным при exit code `1`, а DoD 3 сформулировал
взаимоисключающе («сервер не подключён» и одновременно «вызовы выполняются»). Оркестратор
перепроверил сам; фактическое положение:

`npm run tools:batch -- dev-calls.example.jsonl` даёт **3 вызова, 3 провала**, exit `1`. Все три,
включая `yw_ping`, получают `statusCode: 503` от Yandex Wiki API, каждый за ~27 секунд (ретраи).

**Это внешний сервис, а не регрессия.** Проверено изолированно:
- `https://api.wiki.yandex.net` доступен: без токена отвечает `401` (три попытки подряд) — сеть,
  DNS и split-tunnel VPN исправны;
- с реальным токеном все инструменты получают `503`, стабильно и воспроизводимо;
- `yandex-tracker` в тот же момент времени зелёный: `tools:batch` — 3 из 3 успешных вызовов, exit `0`;
- `packages/servers/yandex-wiki/src/**` не тронут **ни одним** пакетом этого плана — изменения
  ограничены `package.json`, `CLAUDE.md`, новым примером и новым тестом.

**Поправка к первой редакции этой врезки.** Здесь было сказано, что тот же 503 объясняет красный
`test:raw-wire` у wiki. Это не подтвердилось: `packages/servers/yandex-wiki/scripts/raw-wire-test.ts`
работает через мок-сервер ровно так же, как аналог у ticktick (одинаковое число упоминаний
`mockServer`/`localhost`/`createServer` в обоих файлах). Внешний 503 на него влиять не может.
Красный `raw-wire`, который наблюдал пакет 1.3, — **флак**: в последующем полном прогоне
`npm run validate` этот шаг отработал вживую (`cache bypass, force executing`) и прошёл.

**Что остаётся непроверенным:** содержимое примера батча (существует ли в боевой вики страница со
слагом `homepage`, вернёт ли `yw_search` результаты). Синтаксис JSONL и маршрут вызова проверены —
запросы дошли до API и вернулись с внятной ошибкой; смысловая корректность аргументов будет видна
только на живом API. Перепроверить, когда сервис поднимется.

**Открытый вопрос для пользователя:** 503 держится на всём протяжении работ. Стоит выяснить,
деградация ли это сервиса, или проблема с конкретным токеном/организацией.
