# 1.2 — Общие швы волны 2.x (последовательно, вторым)

Разметка параллельности по слою операций не спускается до тестов: два файла общие для
нескольких пакетов сразу, и параллельные агенты затрут там работу друг друга. Этап
приводит их к контрактам `0_CONTRACTS.md` **до** волны.

## Набор файлов

- `tests/integration/helpers/mock-server.ts` — `mockCreateComponentSuccess/403/404`
  шьют `POST /v3/queues/{q}/components` (нужен 2.1), `mockCreateQueueSuccess/403` —
  тело очереди (нужен 2.2);
- `tests/tracker_api/facade/yandex-tracker.facade.test.ts` — один тест на все методы
  фасада: `createField`, `createQueue`, `createComponent`, `createProject`, `createBoard`.

## Чего этап НЕ делает

`src/tracker_api/facade/yandex-tracker.facade.ts` не трогается: сигнатуры фасада заданы
типами DTO, а меняется наполнение DTO, не их имена. Отображение `queueId` инструмента в
`queue` тела делает сервис своего семейства (`facade/services/component.service.ts`) —
файл принадлежит пакету 2.1 и с другими пакетами не пересекается.

Если исполнитель пакета обнаружит, что сигнатура фасада всё же меняется, — это возврат
в оркестрацию, а не правка фасада из пакета.

## Definition of Done

- моки и тест фасада отвечают формам из `0_CONTRACTS.md`; старых форм в них не осталось;
- **тесты пакета в этот момент красные** — это ожидаемое промежуточное состояние: код
  операций ещё старый. Зелёными их делает волна 2.x, и до её конца этап не коммитится
  отдельно.
