# 2.1 — D1: компонент (параллельно)

`POST /v3/queues/{q}/components` — маршрута нет и не было; создание компонента не
работало никогда. Цель — `POST /v3/components` с очередью в теле.

## Набор файлов

- `src/tracker_api/api_operations/component/create-component.operation.ts`
- `src/tracker_api/dto/component/create-component.dto.ts`
- `src/tools/api/components/create-component.{schema,tool,metadata}.ts`
- `src/tracker_api/facade/services/component.service.ts` (отображает `queueId`
  инструмента в `queue` тела; сигнатура фасада при этом не меняется)
- `tests/**` по этим же именам + фикстура `tests/helpers/component.fixture.ts`,
  шаблон `tests/integration/templates/component.json`

## Изменения контракта

- операция теряет параметр `queueId` в сигнатуре: очередь переезжает в DTO
  (`CreateComponentDto.queue`). Инструмент по-прежнему принимает `queueId` — имя
  параметра инструмента менять незачем, меняется только место в теле запроса;
- инвалидация кеша списка компонентов очереди остаётся: ключ берётся из `dto.queue`.

## Definition of Done

- юнит-тест операции требует ровно `POST /v3/components` и тело с `queue`;
- регрессионный тест: **POST**-обращений к `/v3/queues/*/components` в `src/**` нет.
  Формулировка именно про метод: `GET /v3/queues/{q}/components`
  (`get-components.operation.ts`) — законное чтение списка, оно на v3 остаётся;
- моки уже приведены этапом 1.2 — пакет их не правит, а сверяется с ними;
- `npm run validate:quiet` в пакете зелёный.
