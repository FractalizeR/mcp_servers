# Иконка сервера — монограмма FR

Готовые ассеты для пакета 3.1.D. Собраны из глифов `F` и `R`, переведённых в кривые, — от наличия
шрифта на машине пользователя ничего не зависит.

## Происхождение и лицензия

Шрифт — **Marck Script**, Denis Masharov & Marck Fogel, 2011, версия 1.002.
Лицензия — **SIL Open Font License 1.1**, записана в самом файле шрифта
(`name` ID 13 и 14), `OS/2 fsType = 0` (встраивание без ограничений).
Источник файла: [google/fonts, ofl/marckscript](https://github.com/google/fonts/tree/main/ofl/marckscript).

Здесь лежат не файлы шрифта, а контуры двух глифов. OFL распространяется на Font Software;
производная векторная форма в знаке под это определение не подпадает, но атрибуцию сохраняем
сознательно — она ничего не стоит и снимает вопросы.

**Отклонённый вариант:** Roscherk SHA. В файле шрифта отсутствуют все лицензионные поля
(нет copyright, license description, license URL, имени автора), а `OS/2 fsType = 4`
(«Preview & Print») — ограничительный флаг. Утверждение об открытой лицензии происходило от
каталога-агрегатора, а не от самого шрифта. Дополнительно контур втрое тяжелее: ~4 КБ против ~1.4 КБ.

## Варианты

**Выбран `fr-metric`** — расстановка по собственным метрикам шрифта. Остальные оставлены как
альтернативы на случай, если знак не выживет на 16 px в реальном клиенте.

| Файл | Расстановка | SVG в data URI | PNG 48 |
|---|---|---:|---:|
| **`fr-metric`** | **по собственным метрикам шрифта — рабочий вариант** | **2082** | **1159** |
| `fr-tight` | плотная связка, росчерк F заходит на R | 2070 | 1210 |
| `fr-loose` | разрежённая | 2070 | 1083 |
| `fr-circle` | по метрике, в круглой рамке | 2198 | 1841 |
| `fr-square` | по метрике, в скруглённом квадрате | 2218 | 1721 |

Размеры в байтах. Для SVG указана длина строки `data:image/svg+xml;base64,` вместе с содержимым,
для PNG — размер файла. PNG 96 и 256 лежат рядом.

Чтобы сравнить варианты глазами, открой SVG-файлы напрямую — важен размер 16 px, там
рукописные росчерки сливаются первыми.

## Как использовать

- SVG написан с `fill="currentColor"` — знак наследует цвет темы клиента. При растеризации цвет
  подставляется явно (см. `export_assets.py`).
- В массив `icons` кладём **обе** записи: PNG (клиенты обязаны его поддерживать) и SVG
  (поддержка необязательна, но там, где есть, знак масштабируется без потерь).
- `sizes` для PNG — конкретный размер, для SVG — `["any"]`.
- Иконка отдаётся **один раз** в ответе `server/discover`. В per-response `serverInfo` её не
  кладём: поле опционально, а иначе одна и та же картинка осядет в логах по разу на каждый ответ.

## Пересборка

`extract_glyphs.py` печатает метаданные шрифта (включая лицензионные поля и `fsType`) и извлекает
контуры. `build_monogram.py` собирает расстановки и считает вес. Обоим нужен `fonttools`;
растеризация в `export_assets.py` использует `cairosvg`.

```
python extract_glyphs.py <font.ttf> FR glyphs.json
python build_monogram.py <font.ttf> monograms.json
python export_assets.py monograms.json <outdir>
```

Выбор точности: координаты округляются до одного знака. Огрубление до целых экономит ещё около
трети веса, но на 64-единичной сетке начинает быть заметным; поскольку иконка едет один раз за
соединение, экономить незачем.
