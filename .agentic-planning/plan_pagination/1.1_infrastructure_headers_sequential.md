# Этап 1.1 — Инфраструктура: доступ к заголовкам ответа (sequential)

> ✅ ВЫПОЛНЕНО. `HttpResponseEnvelope`/`ResponseHeaders` (types.ts), `normalizeHeaders` + `parseLinkHeader` (http/response/), `getWithResponse`/`postWithResponse` через единый приватный `requestWithResponse` (Axios + ticktick AuthenticatedHttpClient), `MockHttpClient` с FIFO-очередью (`setResponseQueue`) и заголовками. Тесты: infra 237, ticktick 391 — зелёные, сборка монорепо ОК.

**Пакет:** `@fractalizer/mcp-infrastructure`

## Цель
Дать слою операций доступ к заголовкам HTTP-ответа (`Link`, `X-Total-Count`, `X-Total-Pages`), не ломая существующие вызовы `get/post`.

## Архитектурное решение (DP-1, вариант A)
- В `IHttpClient` добавить методы, возвращающие данные **и** заголовки (контракт `{ data, headers }`), для GET и POST (POST нужен для `_search`). `get/post/patch/delete` не меняются.
- Тип `HttpResponseEnvelope<T> = { data: T; headers: Record<string, string> }` (заголовки — нижний регистр ключей, как отдаёт axios).
- Реализация в `AxiosHttpClient`: те же retry/interceptors, но из axios-ответа берём `response.data` + `response.headers`.
- Реализация в `MockHttpClient`: хранилище должно уметь отдавать заголовки per-response (расширить `setResponse`, чтобы принимать опциональные заголовки; дефолт — пустые).

## Контракты (сигнатуры, без реализации)
- `IHttpClient.getWithResponse<T>(path: string, params?: QueryParams): Promise<HttpResponseEnvelope<T>>`
- `IHttpClient.postWithResponse<T>(path: string, data?: unknown): Promise<HttpResponseEnvelope<T>>`
- `MockHttpClient.setResponse<T>(method, path, response, headers?)`

## Edge cases
- Заголовков нет → `headers = {}`, `Link`-парсер вернёт «нет next».
- Регистронезависимость заголовков (`Link` vs `link`) — нормализуем к нижнему регистру.
- Retry: заголовки берём из финального успешного ответа.

## Тест-план
- `getWithResponse`/`postWithResponse` возвращают и data, и заголовки.
- `MockHttpClient` отдаёт сконфигурированные заголовки; при отсутствии — пустой объект.
- Регрессия: существующие `get/post` без изменений (типы и поведение).
