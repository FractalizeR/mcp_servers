## Что проверяет каждый интеграционный тест (единый шаблон)
1. **Верный вызов:** метод, путь, версия API (v2/v3 по таблице в `packages/servers/yandex-tracker/CLAUDE.md`),
   тело и query — сверенные с референсом `yandex_tracker_client/`, а не с нашим же кодом.
2. **Happy path:** ответ соответствует `outputSchema`, ключевые идентификаторы на месте.
3. **Валидация:** невалидные параметры отвергнуты без HTTP-вызова.
4. **Ошибка API:** 404/403 превращаются в контрактную ошибку инструмента.
5. **Batch (где применимо):** смешанный исход даёт обе группы.

## Отдельно про `raw_api_request`
Escape hatch, GET-only. Проверить, что не-GET методы отвергаются, что путь нельзя увести на чужой
хост, и что ответ не проходит фильтрацию полей молча.
